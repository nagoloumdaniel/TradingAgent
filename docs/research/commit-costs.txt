fix(costs): the spread model was wrong by four and a half, and it was copied twelve times

Three corrections the operator asked for, and the third was the one that mattered.

The AI layer was reporting `402 Insufficient Balance` on every signal. The DeepSeek key in
`.env` is valid and the account holds 3,85 USD, both verified against the provider's own
balance endpoint, and a direct call to the Anthropic-compatible endpoint the agent uses returns
200 with `deepseek-flash`. The credit was loaded after the last failure at 12:00, so nothing
needed changing and the layer is operational again. Worth keeping in mind that it runs in
shadow: it never blocks a trade, so a silent outage would go unnoticed.

The console was throwing `UnicodeEncodeError: 'charmap' codec` on every accented line. The
cause is a branch boundary: `use_utf8_console` was called only in the interactive path, after
the early return that selects JSON logging, while the `ConsoleNotifier` prints to `sys.stdout`
in both modes. Stdout therefore stayed on the legacy Windows code page. This is not cosmetic --
on 2026-10-09 an order was refused by the broker and the journal kept nothing of the incident,
six encoding errors in its place. A fix that loses the trace of a failure is worse than no log
at all. The call is now made before the branch, so both modes get UTF-8 and there is one place
to keep right instead of two.

The cost model applied 0,5 basis points of spread. The risk decisions recorded on the demo
account carry 18,424 USD on BTCUSD at about 82 400, which is 2,24 basis points -- 4,5 times
more. That single change, with no other assumption touched, moves the full-dataset factor from
0,9314 to 0,8693. Every campaign this project has run was measured on a market more favourable
than the real one, on the line item that decides profitability.

The value is not a constant scattered across scripts any more. Twelve files each carried
`price * 0.00005`, so correcting the model meant editing twelve places and hoping none was
forgotten. A `campaign_costs` factory now holds the single definition, alongside named
constants for the spread and slippage fractions, and the production scripts call it. The
throwaway tuning scripts keep their own literal on purpose: their reports already document
which costs they used, and rewriting them would erase the traceability of measurements already
published.

Gold is not pushed to bitcoin's number. Its spread is 0,31 USD on a 0,78 band, 40 % of the
budget against 96 % for bitcoin, and all five of its risk decisions were authorised. A spread
is not one fraction of price shared across markets.

One test did its job: `test_the_charged_costs_are_the_documented_ones` failed the moment the
model changed. It now reads the module constants instead of recopying the numbers, so it fails
again the next time rather than passing on a stale expectation.

pytest 319 passed on the backtest, research and console suites; ruff clean; mypy clean over
351 files.
