# Code de conduite

Soyez respectueux, factuel et constructif. Pas de harcèlement, d'attaques personnelles ni de
spam promotionnel (signaux payants, parrainages de courtiers). Les contenus qui enfreignent
ces règles peuvent être supprimés et leurs auteurs bloqués. Pour signaler un problème,
contactez le mainteneur via son profil GitHub.
